Prompt craft

Prompts treated like production code

At Jet2 I classify unstructured customer chats with LLMs in Snowflake Cortex. Every prompt is versioned, tested and measured.

  • 01Context injection grounds the model in the right policy and data.
  • 02Few-shot examples pin down edge cases and the label set.
  • 03Chain-of-thought reasoning before the final answer.
  • 04Structured JSON output so downstream code can trust it.
  • 05Version control and evaluation to track hallucination rates.
classify_chat.prompt · v3 · illustrative
SYSTEM  You are an operations analyst for a travel company.
        Classify each customer chat. Be precise; never guess.

CONTEXT {{ ops_policies }}        # injected at runtime
        {{ live_flight_status }}

EXAMPLES
  "Flight delayed 4h, no update"   → DISRUPTION / delay
  "Can I add a hold bag?"          → NOT_DISRUPTION
  "Hotel overbooked on arrival"    → DISRUPTION / accommodation

REASON  Think step by step about intent and urgency,
        then decide.

OUTPUT  JSON { "label", "category", "confidence", "evidence" }
